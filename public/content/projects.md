MULTI-AGENT RL FOR NETWORK INTRUSION DETECTION is an AI-driven cybersecurity defense system using Multi-Agent Reinforcement Learning to protect critical network assets under resource constraints. Enterprise networks are modeled as graphs using Graph Neural Networks to make agents topology-aware, achieving a 47 percent improvement over baseline metrics using Proximal Policy Optimization (PPO). EXPLORING SEPSIS DETECTION USING DIFFUSION MODELS engineers a Conditional Denoising Diffusion Probabilistic Model (DDPM) for medical time-series, treating vital sign forecasting as a generative re-painting task to visualize outcome distributions, providing superior clinical utility over traditional LSTMs by producing a cloud of possible outcomes rather than a single point estimate. Implemented as a 1D ResNet-style architecture in PyTorch with sinusoidal embeddings for diffusion time-steps. HEALTHCARE DATA MANAGEMENT AND WAREHOUSING SYSTEM is a normalized PostgreSQL schema in 3NF and a Star Schema data warehouse optimized for complex analytical queries and high-performance reporting. Built with an automated dbt pipeline engineering Fact and Dimension tables for hospital revenue and patient workload metrics. The full stack of database, API, and pipeline is containerized using Docker and Docker Compose. Performance tuning and database indexing reduced query execution time from 616 milliseconds to 53 milliseconds, roughly a 90 percent improvement. DEAFINE is a Python accessibility tool providing real-time speaker detection and live transcription using the ElevenLabs Speech-To-Text API for deaf and hard-of-hearing users. Implements real-time audio processing with WebSockets and batched API calls to avoid redundant calls during silence. Won the Best Use of ElevenLabs Award at the MLH-UB Hackathon. MULTI MODAL GENRE PREDICTION is a fusion model integrating textual plot summaries via LSTM and visual movie posters via MLP to classify movie genre across a dataset of 100,000+ movies. Implements custom data augmentation and undersampling to handle class imbalance across six main genres, achieving 72 percent accuracy on the integrated multi-modal system.
